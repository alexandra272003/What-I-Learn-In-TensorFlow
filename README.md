# What I Learn In TensorFlow 🧠🤖
Welcome to my repository dedicated to tracking my learning journey, experiments, and progress with **TensorFlow** and **Deep Learning** for Data Science. 

This repository contains structured Jupyter Notebooks covering foundational concepts, hands-on implementations, and regression workflows.
## 🚀 Repository Contents
*   **`00_fundamental_of_Ternsorflow.ipynb`**
    *   Introduction to Tensors (scalars, vectors, matrices).
    *   Manipulating tensors and checking their shapes.
    *   TensorFlow data types and mathematical operations.
    *   Matrix multiplication and indexing.
*   **`01_Neural_Network_Regression_with_TensorFlow.ipynb`**
    *   Building a neural network regression model.
    *   Defining input and output shapes.
    *   Configuring steps in modeling: Creating, compiling, and fitting a model.
    *   Evaluating model performance using metrics like MAE and MSE.
    *   Tuning hyperparameters (learning rate, layers, hidden units).
## 🛠️ Prerequisites & Setup
To run these notebooks locally, you need Python installed along with the required data science libraries.
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd What-I-Learn-In-TensorFlow
   ```
2. **Install dependencies:**
   Make sure you have TensorFlow, Jupyter, NumPy, and Pandas installed.
   ```bash
   pip install tensorflow jupyter numpy pandas matplotlib
   ```
3. **Launch the notebooks:**
   ```bash
   jupyter notebook
   ```
